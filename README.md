# data-cleaning-practice
Python data cleaning and preprocessing practice using Pandas and NumPy as part of my research internship at the Lithuanian Energy Institute.
## Practical Data Cleaning – Household Electricity Consumption

### Completed Work
- Dataset loading and initial inspection.
- Numerical data type correction.
- Missing value detection and percentage calculation.
- Analysis of consecutive missing measurements.
- Statistical analysis of missing gap lengths.

### Key Findings
- Total observations: 2,075,259.
- Missing observations per measurement column: 25,979 (1.25%).
- Number of missing gaps: 71.
- Longest missing gap: 7,226 consecutive observations.

### Next Steps

- Duplicate detection and removal.
- Data type and formatting corrections.
- Inconsistent data detection.
- Outlier detection and treatment.
